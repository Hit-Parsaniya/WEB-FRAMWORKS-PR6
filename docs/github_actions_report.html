🔍 Continuous Integration vs Deployment

This practical showcases Continuous Integration (CI): automatic code checkout, dependency provisioning, static analysis (ESLint), and automated regression testing upon code commits. It protects the main branch from regressions before deployment.

🛡️ Diagnostic Analysis: Assertion Failure vs Path Error

Both errors result in exit code 1 at the npm test step. However, a genuine assertion failure executes test cases and reports expected vs received values. A wrong path error fails prematurely during runner discovery with No tests found without running any assertions.
